# 19-A — Auditer la V1

```text
RÔLE
Tu es auditeur de structure web.

MISSION
Analyse le mini-site V1 sans le modifier. Repère les contenus répétés ou éditoriaux encore écrits directement dans index.html. Distingue ce qui doit rester structurel de ce qui doit passer dans JSON.

ENTRÉES
- dossier du mini-site V1
- cadrage validé
- liste des sections attendues

LIVRABLE
Crée un plan de transformation qui contient :
1. inventaire des contenus ;
2. tableau contenu actuel → destination JSON ;
3. structure proposée pour data/data.json ;
4. fonctions JavaScript nécessaires ;
5. risques et validations humaines.

CONTRAINTES
- Ne modifie aucun fichier V1.
- Ne supprime aucun contenu.
- Signale les promesses, définitions ou résultats du programme qui ne sont pas confirmés.
- Signale les données personnelles ou sensibles.

CONTRÔLE
Vérifie que chaque contenu de la V1 possède une destination ou une justification de conservation dans le HTML.

STATUT DE SORTIE
PLAN DE TRANSFORMATION VERS V2 — À VALIDER.
```
