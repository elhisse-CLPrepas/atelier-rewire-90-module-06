# 19-D — Afficher dans le DOM

```text
RÔLE
Tu es développeur front-end orienté accessibilité.

MISSION
Crée dynamiquement dans le DOM :
- les trois principes ;
- le profil professionnel et l’intention de l’auteur ;
- les quatre axes de production ;
- les cartes de ressources ;
- les six étapes de la méthode ;
- les règles de validation ;
- la FAQ.

RÈGLES
- Utilise document.createElement et textContent.
- Conserve des titres hiérarchisés.
- Ajoute des textes alternatifs aux images.
- Ajoute aria-live au statut des ressources.
- Rends la FAQ utilisable au clavier.
- Affiche un message explicite si le tableau des ressources est vide.
- N’affiche aucune coordonnée personnelle du dossier source.

CONTRÔLES
- Les données viennent du JSON et non d’un doublon caché dans le HTML.
- Le DOM reste lisible sans erreur si une section optionnelle manque.
- Les cartes s’adaptent au mobile.

SORTIE
Mini-site V2 dynamique et accessible.
```
