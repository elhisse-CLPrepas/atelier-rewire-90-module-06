# Checklist avant le premier commit

- [ ] Je travaille sur une copie nettoyée.
- [ ] La fiche candidature originale est hors du dossier.
- [ ] Aucun téléphone, email ou identifiant n’est présent.
- [ ] Aucun fichier `.env` ni secret n’est présent.
- [ ] Les fichiers ZIP et les dossiers de rendu sont exclus.
- [ ] Le README explique le lancement sur localhost.
- [ ] Le JSON est valide.
- [ ] Les quatre états sont testables.
- [ ] Le statut « à valider » est visible.
- [ ] `git status` ne montre que les fichiers attendus.
