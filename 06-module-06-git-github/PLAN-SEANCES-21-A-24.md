# Intégration du cas REWIRE dans les Séances 21 à 24

| Séance | Travail sur le cas réel | Livrable candidat |
|---|---|---|
| 21 — Comprendre et organiser | Lire le pack, distinguer public et privé, expliquer l’arborescence | Inventaire, README et `.gitignore` |
| 22 — Atelier Git local | Initialiser Git, créer trois commits et lire l’historique | Dépôt local propre et historique commenté |
| 23 — Workflow GitHub | Créer le dépôt distant, pousser `main`, créer une issue et une branche | Dépôt, issue et branche visibles |
| 24 — Revue et preuve | Ouvrir une pull request, contrôler, corriger, fusionner et taguer | Pull request validée et version repérée |

## Progression pédagogique

Le candidat ne commence pas par les commandes. Il commence par décider ce qui peut entrer dans le dépôt. Git enregistre ensuite une production déjà organisée.

## Évaluation

- 25 % organisation et confidentialité ;
- 25 % qualité des commits ;
- 25 % workflow issue, branche et pull request ;
- 25 % tests et preuves.
